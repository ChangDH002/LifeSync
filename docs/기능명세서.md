# 기능 명세서

## 주요 기능

| 기능 | 설명 | 관련 화면 |
|------|------|-----------|
| 회원가입 / 로그인 | 이메일 가입·로그인 및 Google/Kakao 소셜 로그인(JWT 인증) | 로그인, 회원가입 |
| 생활습관 설문 | 생활·인지·성향 데이터를 입력받아 치매 위험군 유형 분석 | 설문 |
| 위험군 유형 분석 | 설문 결과로 운동 부족형·인지활동 부족형 등 페르소나 분류 | 설문 결과, 마이페이지 |
| 치매 예방 정보 | 치매 유형·특징·예방법 등 인지 건강 정보 제공 | 정보 |
| AI 챗봇 상담 | SBERT/Gemini 기반 대화형 상담·안내 | 챗봇 |
| 인지훈련 게임 | 기억력·판단력·주의력·언어 4종 게임 및 결과 분석 | 인지훈련 허브, 게임, 결과 |
| 루틴 관리 | 사용자 상태에 맞춘 생활·운동·인지 루틴 추천 및 완료 기록 | 루틴 |
| 비금전적 보상 | 일일 미션 달성으로 나무 키우기(아바타) | 아바타, 마이페이지 |
| 마이페이지 / 활동 기록 | 활동 내역과 진행 상황 확인 | 마이페이지 |
| 설정 | 계정·서비스 설정 | 설정 |

## 인지훈련 게임 상세

| 게임 | 훈련 영역 |
|------|-----------|
| 카드 뒤집기(기억력) | 단기 기억력 |
| 판단력 게임 | 상황 판단·의사결정 |
| 주의력 게임 | 집중력·주의 지속 |
| 언어 게임 | 언어·어휘 능력 |

각 게임 종료 후 결과 페이지에서 점수와 간단한 분석을 제공합니다.

## 비기능 요구사항(요약)

- 고령층 친화적 UI(큰 글자·명확한 버튼)
- 반응형 레이아웃
- JWT 기반 인증 및 보호 라우트(`RequireAuth`)
- **본 서비스는 의료적 진단을 제공하지 않습니다** — 의료적 판단/치료는 전문기관 안내
