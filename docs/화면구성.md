# 화면 구성

각 화면의 목적과 주요 구성 요소입니다. 실제 캡처 이미지는 [screenshots/](screenshots/)에 추가하세요.

| 화면 | 경로 | 목적 / 구성 |
|------|------|-------------|
| 랜딩(홈) | `/` | 서비스 소개, 주요 기능 안내, 시작하기/정보 보기 CTA, 의료 면책 문구 |
| 로그인 | `/login` | 이메일 로그인, Google/Kakao 소셜 로그인 |
| 회원가입 | `/signup` | 이메일 회원가입 |
| 설문 | `/survey` | 생활습관·인지·성향 설문 입력 및 위험군 분석 |
| 정보 | `/information` | 치매 유형·특징·예방법 등 인지 건강 정보 |
| 챗봇 | `/chatbot` | AI 챗봇 상담(질문 입력 → 응답) |
| 인지훈련 허브 | `/training` | 4종 게임 진입, 진행 상황 안내 |
| 인지훈련 게임 | `/training/{memory\|judgment\|attention\|language}` | 게임 플레이 화면 |
| 인지훈련 결과 | `/training/{...}/result` | 게임 점수·분석 결과 |
| 루틴 | `/routine` | 맞춤 루틴 추천 및 완료 체크 |
| 아바타 | `/avatar` | 미션 달성 보상(나무 키우기) |
| 마이페이지 | `/mypage` | 활동 기록, 진행 상황 요약 |
| 설정 | `/settings` | 계정·서비스 설정 |
| 약관/개인정보/의료고지 | `/terms`, `/privacy`, `/medical-notice` | 정책 및 의료 면책 안내 |
| 404 | `*` | 존재하지 않는 경로 처리 |

> 로그인이 필요한 화면(마이페이지·설정·아바타·루틴·인지훈련·챗봇)은 `RequireAuth`로 보호되어,
> 비로그인 상태에서 접근 시 로그인 화면으로 안내됩니다.

## 캡처 가이드(시연용)

`screenshots/` 폴더에 아래 순서로 캡처를 넣으면 시연 흐름을 설명하기 좋습니다.

1. 랜딩 페이지
2. 설문 입력/결과
3. 챗봇 대화
4. 인지훈련 게임 + 결과
5. 루틴 관리
6. 마이페이지
