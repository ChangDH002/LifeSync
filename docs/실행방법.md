# 실행 방법

LifeSync는 **프론트엔드 / 메인 백엔드 / AI 챗봇** 세 부분으로 구성됩니다.
화면만 확인하려면 프론트엔드만 실행해도 되지만, 로그인·설문·챗봇 등 전체 기능을 보려면 세 서비스를 모두 실행합니다.

| 서비스 | 위치 | 포트 |
|--------|------|------|
| 프론트엔드 (Vite) | `frontend` | 5173 |
| 메인 백엔드 (FastAPI) | `backend` | 8000 |
| AI 챗봇 (FastAPI) | `ai/AI_Chatbot` | 8001 |

---

## 1. 프론트엔드

```bash
cd frontend
npm install
npm run dev      # 개발 서버: http://localhost:5173/LifeSync/
```

- 프로덕션 빌드 확인:
  ```bash
  npm run build    # 결과물: frontend/dist
  npm run preview  # 빌드 결과 미리보기
  ```
- 환경 변수: `frontend/.env.example`를 복사해 `frontend/.env`로 만들고 `VITE_API_URL`을 백엔드 주소(`http://localhost:8000`)로 설정합니다.

## 2. 메인 백엔드 (FastAPI)

```bash
cd backend
python -m venv .venv
.venv\Scripts\activate           # Windows
# source .venv/bin/activate      # macOS/Linux
pip install -r requirements.txt
uvicorn app.main:app --reload    # http://127.0.0.1:8000
```

- API 문서: `http://127.0.0.1:8000/docs`
- 환경 변수: 루트 `.env.example`를 복사해 `backend/.env`로 만들고 `MONGODB_URL`, `JWT_SECRET_KEY` 등을 채웁니다.
- MongoDB(로컬 `mongod` 또는 Atlas)가 실행 중이어야 합니다.

## 3. AI 챗봇 (FastAPI)

```bash
cd ai/AI_Chatbot
python -m venv .venv
.venv\Scripts\activate
pip install -r requirements.txt
uvicorn main:app --reload --port 8001   # http://127.0.0.1:8001
```

> 최초 실행 시 SBERT 모델 로딩으로 시간이 걸릴 수 있습니다.

---

## 한 번에 실행하기 (참고)

세 서비스를 각각 다른 터미널에서 실행하는 것을 권장합니다.

1. 터미널 A: `cd backend && uvicorn app.main:app --reload`
2. 터미널 B: `cd ai/AI_Chatbot && uvicorn main:app --reload --port 8001`
3. 터미널 C: `cd frontend && npm run dev`

## 자주 겪는 문제

- **챗봇이 응답하지 않음**: AI 챗봇(8001)이 떠 있는지 확인하세요. 8001을 빠뜨리기 쉽습니다.
- **로그인/설문 오류**: 메인 백엔드(8000)와 MongoDB 연결, `.env` 값을 확인하세요.
- **포트 충돌(Windows)**: `Get-Process node, python -ErrorAction SilentlyContinue | Stop-Process -Force`
