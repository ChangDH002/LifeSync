# 배포 방법 (GitHub Pages + GitHub Actions)

프론트엔드는 GitHub Actions 워크플로우(`.github/workflows/deploy.yml`)로 빌드되어 GitHub Pages에 배포됩니다.

- 배포 주소: **https://changdh002.github.io/LifeSync/**

---

## GitHub Pages 설정 절차

1. GitHub 저장소 → **Settings** → **Pages** 로 이동합니다.
2. **Source** 를 **"Deploy from a branch"가 아니라 "GitHub Actions"** 로 변경합니다.
3. 변경 후 `main` 브랜치에 푸시하거나, **Actions** 탭에서 *Deploy LifeSync Frontend to GitHub Pages* 워크플로우를 수동 실행(`Run workflow`)합니다.
4. **Actions** 탭에서 워크플로우의 `build` → `deploy` 잡이 모두 성공(초록 체크)했는지 확인합니다.
5. 배포가 끝나면 `https://changdh002.github.io/LifeSync/` 에 접속해 **README가 아니라 LifeSync 랜딩 페이지**가 보이는지 확인합니다.

## ❌ 사용하면 안 되는 설정

```text
Source: Deploy from a branch
Branch: main
Folder: / (root)
```

이 설정은 **저장소 루트 폴더를 그대로 배포**하기 때문에, 루트의 `README.md`가 화면에 문서처럼 노출됩니다.
실제 React/Vite 앱이 아니라 README 내용이 보이는 원인이므로 **사용하지 않습니다.**
반드시 위의 **"GitHub Actions"** 방식을 사용하세요.

## 동작 원리 요약

- `deploy.yml`이 `frontend`에서 `npm ci` → `npm run build`를 실행하고, 결과물 `frontend/dist`를 Pages에 업로드합니다.
- Vite `base`가 `/LifeSync/`로 설정되어 있어 asset 경로가 하위 경로에 맞게 생성됩니다.
- 빌드 후 `index.html`을 `404.html`로 복사하여, SPA 라우팅에서 새로고침/직접 접근 시에도 404가 나지 않도록 처리합니다.

## 백엔드 / AI 배포 (참고)

백엔드와 AI 챗봇은 `render.yaml`을 통해 Render에 배포합니다(`backend`, `ai/AI_Chatbot`).
GitHub Pages는 정적 프론트엔드만 호스팅하므로, 로그인·설문·챗봇 등 백엔드 연동 기능은 백엔드/AI 서버가 함께 떠 있어야 동작합니다.
